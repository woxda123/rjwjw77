# WOX · База знаний — Telegram-бот для подготовки к поступлению

Тесты по предметам, баллы, уровни, рейтинг, работа над ошибками и настройки.
Языки: **русский, o'zbek (латиница), ўзбек (кириллица), English**.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env        # впишите BOT_TOKEN (у @BotFather) и свой ADMIN_IDS
python main.py
```

Проверка контента без запуска бота: `python tests/test_content.py`

## Возможности

- 📚 9 предметов: математика, физика, химия, биология, информатика, право, английский, IELTS, история Узбекистана + режим «Микс»
- 🟢🟡🔴 три уровня сложности; баллы 10 / 15 / 25 и бонус +5 за каждые 3 верных подряд
- 🏅 уровни от «Новичка» до «Легенды», 🔥 серия дней, 📊 статистика по предметам
- 🏆 рейтинг за неделю и за всё время
- 🔁 работа над ошибками — повтор вопросов, на которые вы отвечали неверно
- ⚙️ настройки: язык, число вопросов в тесте (5–20), пояснения, перемешивание вариантов, сброс статистики
- 🛠 админ: `/admin` (статистика), `/broadcast текст` (рассылка)

## Как устроены языки

| Код | Язык | Как хранится |
|-----|------|--------------|
| `ru` | Русский | `bot/strings/ru.py`, ключ `ru` в вопросах |
| `uz` | O'zbekcha | `bot/strings/uz.py`, ключ `uz` в вопросах |
| `en` | English | `bot/strings/en.py`, ключ `en` в вопросах |
| `uzc` | Ўзбекча | **строится автоматически из `uz`** (`bot/translit.py`) |

Кириллица не требует отдельных переводов: при добавлении или правке узбекского
текста кириллическая версия обновляется сама. Английские слова, формулы и
аббревиатуры (She goes, CPU, H₂O, pH…) остаются латиницей: бот считает «чужими» все
латинские токены, которые есть в русском тексте того же вопроса.

Если автоперевод где-то неточен, добавьте в вопрос явный ключ `"uzc"` — он приоритетнее.

## Как добавить вопросы

Файлы `data/questions/<предмет>.json`. Формат вопроса:

```json
{"id":"math_013","d":2,
 "q":{"ru":"…","uz":"…","en":"…"},
 "o":["вариант 1","вариант 2","вариант 3","вариант 4"],
 "a":1,
 "e":{"ru":"пояснение","uz":"izoh","en":"explanation"}}
```

- `d` — сложность 1–3, `a` — индекс верного ответа (с 0), `id` уникален
- `o` — общий список (числа, формулы, английские варианты) или `{"ru":[…],"uz":[…],"en":[…]}`, если варианты нужно переводить
- ошибки в формате ловятся при старте бота и командой `python tests/test_content.py`

## Структура

```
main.py              запуск
bot/config.py        токен, баллы, языки
bot/i18n.py          тексты и названия предметов
bot/translit.py      латиница → кириллица
bot/strings/         ru / uz / en
bot/questions.py     загрузка и проверка базы вопросов
bot/db.py            SQLite (пользователи, ответы, ошибки, рейтинг)
bot/handlers/        меню, тесты, админка
data/questions/      вопросы по предметам
tests/               проверки контента и транслитерации
```
